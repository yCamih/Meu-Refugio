# Meu Refúgio

Projeto em HTML, CSS e JavaScript voltado para saúde mental e autoconhecimento.

## Como usar

1. Extraia o arquivo ZIP.
2. Abra o arquivo `index.html` no navegador.
3. Escolha uma emoção, escreva no diário e salve seu registro.

Os dados ficam salvos no próprio navegador usando localStorage.
